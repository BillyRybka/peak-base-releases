# Peak Base

Your business brain: notes and files your whole team and your AI work in, on your own server.

## Download

- **Windows:** [PeakBase-Windows.exe](https://github.com/BillyRybka/peak-base-releases/releases/latest/download/PeakBase-Windows.exe). If Windows says it protected your PC, click **More info**, then **Run anyway**.
- **Mac:** [PeakBase-Mac.dmg](https://github.com/BillyRybka/peak-base-releases/releases/latest/download/PeakBase-Mac.dmg). Drag Peak Base into Applications, then run once in Terminal: `xattr -cr "/Applications/Peak Base.app"`

The app updates itself after that.

Setup guide: [server/CLIENT-SETUP.md](server/CLIENT-SETUP.md). Compose file for Hostinger Docker Manager: `https://raw.githubusercontent.com/BillyRybka/peak-base-releases/main/server/docker-compose.yml`
